# 学習システム

数値の初期値は `services/core/lq/learning_config.yaml` にあり、変更できます。いずれも研究で確定した最適値ではありません。
参考にした設計原則（想起練習、間隔をあけた学習、異なる例での練習）は、この配分や閾値の最適性を示すものではありません。

## 5つの指標を混ぜない

| 指標 | 中身 | どこで |
|---|---|---|
| 学習量 | 学習 Unit 数・回答数・ラジオ再生時間・XP | 成長記録「学習量」 |
| 初見の成績 | 下の条件を満たす客観採点。本番形式とアレンジ条件（選択肢読み上げ等）は別集計 | `category = first`、`presentation` |
| 既出問題の定着 | 期限が来た復習での結果 | `category = review` |
| 補助付き結果 | 追加再生・速度変更・英文表示・ヒント・問いの文字表示 | `category = assisted` |
| 自己申告・ラジオ接触 | ラジオ後の「自分では正解／不正解／不明」、ラジオで聞いた範囲 | `self_reports`・`radio_programs` |

## 初見として数える条件（`rules.judge_strict_first`）

- その attempt を始める**前**に、同じ台本・音声・答え・解説に接触していない（同じ attempt 内の最初の再生は接触扱いしない）。同一台本の別設問版・改版・別モード版も接触済みとみなす。
- 規定回数以内（規定2回の問題を2回聞くのは補助ではない）・通常速度・回答前の補助なし。
- 開始後に別経路（ラジオ番組作成・別タブ）で答えに触れていない。
- 自動採点された最初の確定回答で、全設問に回答（スキップなし）。無効化・デモ以外。
- train セッションであること（review・assessment・radio は別集計）。
- 同時に2つのタブで開いても同じ attempt を返し、「初見」権は一つだけ。
- オフライン解答は端末に問題を配った時点以降の接触履歴で判定（配布パックに答えは含まれない）。ラジオのダウンロードや番組作成は、その時点で「解答へアクセス可能になった」と記録される。

## 出題の変化（`domain/recommend.py`、純粋関数・seed 固定で再現可能）

1. **直後の再確認**: 誤答した技能・補助が必要だった技能（`need_signal`）を、次の未開始枠でその技能を問う未接触 Unit に優先的に入れ替える。少数でも使えるが、技能全体を苦手とは判定しない。
2. **弱点判定**: 初見の技能観測（1 Unit から1技能につき1観測、Unit 内の該当設問の平均）が直近20件中5件以上あり平均70%未満なら「重点練習の対象」。5件未満は「参考値（判定中）」、0件は「未測定」。
3. **難度帯（1〜5、モードごと）**: 今の難度帯に移ってから、異なる音声の適格な初見 Unit（全設問回答済み）が10件以上集まったら、直近最大20件の平均が85%以上で+1、60%未満で−1、それ以外は維持。1学習日に最大1段階。自己申告・ラジオ・補助付き正解・解き直しは使わない。他モードの難度はコピーしない。
4. 推薦理由（「数字・日時・否定を再確認」「期限が来た復習」「未測定の『推論』を広げる」等）と使ったパラメータは枠ごとに保存し、画面に表示。

形式・技能・話題・難度は別属性。類題（同じ family）は「転移練習」として使えるが、実力チェックには過去接触 family を混ぜない。

## 復習（段階式）

間隔 1・3・7・14・30 日。初回学習の翌日に最初の復習。期限が来た復習で**全設問を補助なしで正解**したときだけ次の段階へ。
誤答・部分回答は翌日へ戻す。補助付きの正解は段階を据え置き翌日へ。期限前の反復（解説直後の解き直しを含む）では段階を進めない。
Unit 単位で管理し、設問ごとに予定を作らない。自己申告の誤答は復習を作れるが、自己申告の正解は段階を進めない。
ラジオからの「あとで再聴」は別種（`relisten`）の予定。履歴に変更理由（`reason_ja`）を残す。

## 日課（`services/plans.py`）

- 目標時間（初期30分、5モード合計）を、期限の来た復習40%・弱点を問う新しい Unit 40%・範囲を広げる初見20% で埋める。履歴のない枠は範囲拡大へ振り替える。
- 開始時に計画ID・学習日・モード・枠数・予定時間・各枠の時間上限を固定。1枠 = 1 Unit（途中で切らない）。
- Unit 終了ごとに、未開始かつ未予約の枠だけを、同じモード・時間上限内の別 Unit に入れ替える。枠数・必須量は増やさない。新教材の到着や設定変更でも増えない。
- 「残りをこのモードに変更」だけが未開始分を組み直し、完了分と残り時間予算を引き継いで新しい予定量を表示する。
- 解答型の枠は「全設問に回答 + 解説確認」で完了（誤答でも完了）。部分回答・スキップは未完のまま、続けるか別の問題に替える。
- オフライン用に払い出した枠は予約済みで、Unit の版と `assignment_version` を固定。解除時に版を進め、古い端末の割当は自由練習として記録する。
- 教材が足りないときは理由と短い予定量を表示。未生成の教材を再生可能とは表示しない。
- ラジオ中心の計画は再生の進み具合（実際に再生した範囲の和集合が各 Unit の90%以上）で達成を判定。

## 学習日と報酬

学習日はサーバー時刻で判定（初期 Asia/Tokyo 04:00 切替）。計画は `learning_day` を固定し、日をまたいだ解答や翌日の同期も元の計画日に一度だけ計上。
タイムゾーンを変えても dedupe_key が学習日単位なので二重に報酬を受け取れない。端末時計は参考情報として保存するだけ。

XP: 解答型 Unit の全設問提出と解説確認 10、期限が来た復習 +5、ラジオ Unit の実再生90%以上 5、日次計画完了 20（1日1回）。同じ Unit の基本XPは1学習日1回。
レベル = 1 + floor(累積XP / 100)。XP・レベル・連続日数は継続の指標で、能力推定ではない。休んでも過去の成績は消えない。

## 実力チェック（assessment）

- 教材管理で「不足分を生成」（pool = assessment、通常の練習・ラジオ候補に出ない）→ 全形式がそろったら「組み立てる」。形式・解答欄・話者・規定回数・採点グループ・exam 音声を検証し、短縮版は作らない。
- 開始時に接触履歴（同じ Unit・同じ音声・同じ family）を再確認し、接触があればそのセットは無効（STALE）。
- 所要時間は完成音声の timeline の合計で、開始前に表示。オンライン必須。途中の補助・解説・本文表示なし。
- 共通テスト 2026: 37 解答欄・100 点（18〜21、28〜29、30〜31 は全問正解時のみ）。英検は正答数とPart別正答数のみ（CSE・合否・100点換算はしない）。C1/C2 は「アプリ内実力チェック」。
- 提出後、教材は練習プールへ移り復習に使えるが、初見としては二度と数えない。

## 無効化

誤生成と分かった Unit は教材管理で無効化。履歴は残し、成績・推薦・一覧から除外し、難度帯を有効な結果だけで再計算。未開始の枠は代替 Unit に差し替える。
