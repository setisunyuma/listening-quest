アプリの表示（iPhone 実機の管理画面、2026-11-14 11:30 JST）: 残り **0.8934 USD**（= 1.00 − 開発環境分 0.07 − 0.0366）。
予算全体の計上額: 開発環境 0.069881（台帳上は 0.07 として引き継ぎ）+ 公開先 0.0366 = **約 0.1066 USD**。
値は画面の表示（小数第4位）から転記。実際の請求額は OpenAI の請求画面が正。

iPhone 実機での確認（オーナー、2026-11-14 11:35 JST）: タップで再生・音が出る・解答後に正誤と解説が出る、を確認。英文の内容も整合。
**不具合**: 「Man」の行が女性の声、「Woman」の行が男性の声で読まれていた。原因は、声の割り当てが話者の性別（`voice_hint`・表示名）を見ず、登場順に割り振っていたこと。
修正: 表示名（Man / Woman / Mr. など）、なければ `voice_hint` に合う声の候補から選ぶ（`LQ_TTS_MALE_VOICES` / `LQ_TTS_FEMALE_VOICES`）。回帰テスト `test_voices_follow_speaker_gender`。
音声認識は話者の性別を判定しないため、この取り違えは自動の音声確認では検出できなかった。作成済みのこの 1 教材は声が逆のまま。

再デプロイ後の確認（オーナー、2026-11-14 12:0x JST）: PR #3（merge `5015636`）が Railway で ACTIVE。再起動後もこの教材の音声が再生でき、ボリューム `/data` の保持を確認。
修正後の声の割り当ては、実音声では未確認（確認には実 API で 1 教材の生成が必要、約 0.04 USD）。
